# Claude Skills

My personal collection of Claude Code / agent skills.

## Skills included

### find-skills
Helps discover and install other agent skills from the open ecosystem (skills.sh).
Originally from [vercel-labs/skills](https://github.com/vercel-labs/skills).

**Install this skill into a project:**

```bash
npx skills add klonz484/claude-skills --skill find-skills
```

Or install globally:

```bash
npx skills add klonz484/claude-skills --skill find-skills -g
```

## Adding more skills

Drop additional skill folders (each containing a `SKILL.md`) into this repo.
